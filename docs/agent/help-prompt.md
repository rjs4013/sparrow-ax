# /ax:help 본문 (단일 원본)

이 커맨드는 **읽기 전용**이다. 파일을 만들거나 고치지 않고, 게이트를 실행하지 않고, `AskUserQuestion`을 띄우지 않고, 작업을 시작하지 않는다.

인자: `$ARGUMENTS`

## 원천
출력은 하드코딩하지 않고 아래 파일을 **읽어서** 만든다. 문서가 바뀌면 출력도 바뀌어야 하고, 설치되지 않은 경로는 나오면 안 된다.
- `AGENTS.md` (종료 지점, 환경 모드, 도구), `docs/agent/pipelines.md` (경로 정의와 매트릭스), `docs/agent/intake.md` (채널), `docs/agent/environment.md` (환경 절차), `docs/agent/risk-signals.md` (위험 신호)
- `.claude/commands/ax/` 디렉터리 (실제 설치된 경로 커맨드 목록. `help.md`는 제외)

## 규칙
1. 사람이 읽는 것이므로 파일 경로보다 "언제 · 어떻게 · 무엇이 나오나"를 앞에 둔다.
2. 인자 없는 출력은 화면 한 장(약 40줄) 안에 들어간다. 상세는 `/ax:help <경로>`로 미룬다.
3. 설치된 경로만 표시한다 (`.claude/commands/ax/`에 파일이 있는 것).

## 호출별 출력
| 호출 | 출력 |
|---|---|
| `/ax:help` | 현재 설정 한 줄(환경 모드 · 사용 채널 · 종료 지점 · 도구) + 설치된 경로의 요약표(경로 · 언제 · 호출 예 · 생략하는 것 · 끝나는 곳) + 위험 신호 승격 한 줄 + 다음 한 걸음 |
| `/ax:help <경로>` | 상세 (아래 순서 고정) |
| `/ax:help intake` · `env` · `signals` | 접수 규칙 · 환경 절차 · 위험 신호 표의 요약 |

## `/ax:help <경로>` 출력 항목 (순서 고정)
1. 언제 쓰나 / 쓰지 말아야 할 때
2. 호출 예 — 채널별로 하나씩 (프롬프트 / 문서 경로)
3. 진행 단계 — 단계 매트릭스의 해당 열을 문장으로
4. 무엇을 물어보나 — 이 경로에서 `AskUserQuestion`이 뜨는 지점과 기본값
5. 산출물과 완료 조건
6. 되돌리는 방법 — 현재 환경 모드 기준 한 줄
7. 이 경로가 승격되는 위험 신호

## 인자 없는 출력 형식
```
sparrow-ax — 에이전트 파이프라인
환경: {환경 모드} · 채널: {채널 목록} · 종료 지점: {종료 지점} · 도구: Claude Code

경로      언제                         호출 예                         생략하는 것      끝나는 곳
(설치된 경로마다 한 줄)

* 위험 신호({요약})가 감지되면 어느 경로든 자동 승격됩니다.

애매하면 더 무거운 쪽을 고르거나, 경로 없이 요청만 적으면 접수 단계에서 제안합니다.
상세: /ax:help <경로> · 접수 규칙: /ax:help intake · 되돌리기: /ax:help env
```
