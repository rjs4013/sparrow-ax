### 가정
- 결정 5에 따라 문서의 "3차 확인(물품식별번호)"을 "식별번호 기준 조회 필터"로 해석했다. 문서 8장의 조회 기능("물품식별번호를 통한 특정 제품 확인")과 일치한다. 필터가 아니라 **저장 단계의 제외 조건**을 원하면 알려 달라.
- 수집 대상 업체는 문서 3.1의 9개사다(스패로우 포함).
- 금액 · 날짜 형식은 API 응답을 본 뒤 정한다.

### 사람이 준비할 것 (구현 시작 조건)
1. **보안SW 물품분류번호 목록** (결정 2)
2. **9개사의 나라장터 등록 상호** 정확한 표기 (결정 3): 스패로우, 에스에스알, 정보라인, 코드마인드, 하로스, 나일소프트, 레드펜소프트, 코드원, 래브라도랩스
3. 공공데이터포털에서 **조달청 OpenAPI 서비스키 발급**과, 납품요구 조회에 쓸 **서비스명 · 엔드포인트 확인**. 키는 `.env`의 `G2B_SERVICE_KEY`에 Decoding(원문) 키로 넣는다. 대화나 기록에 붙여 넣지 않는다.
4. API 응답 필드를 본 뒤 **고유 키 조합 승인** (결정 4)

서비스키와 엔드포인트 없이도 2~3번이 준비되면 필터 함수(분류번호 · 업체명)와 날짜 계산은 샘플 입력으로 먼저 구현할 수 있다.
