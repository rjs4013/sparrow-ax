### 가정
- SP영업 메일 알림 기능은 **구현 범위 밖**으로 기록한다. 요구사항 원본 문서는 고치지 않았다(정리는 요청 시 `docs` 경로로).
- 금지 항목에서 메일 발송을 고른 것은 "메일 코드가 생기더라도 실제 발송은 사람 확인"으로 해석했다.
- 사용 도구는 Claude Code로 확정(현재 세션). 다른 CLI용 진입 파일은 만들지 않았다.
- 반복 상한 3회, 경로 커맨드는 내장 커맨드와의 충돌을 피하려 모두 `ax:` 네임스페이스로 만들었다.
- 시크릿 파일 접근(`.env*`)을 확인 대상에 넣은 것은 지침의 기본 예외이며 사용자가 따로 고른 항목은 아니다.
- 나라장터 API 실호출은 사용자가 금지 항목으로 고르지 않았으므로 제한하지 않았다.
